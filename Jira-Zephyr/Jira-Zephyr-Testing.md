# Jira and Zephyr Scale Testing Project

## Project Overview

This project demonstrates hands-on experience using Jira for Agile/Scrum project management and Zephyr Scale for test case management and test execution.

---

## Jira Activities

The following Jira activities were practiced:

- Created Epics and User Stories
- Added Story Points to User Stories
- Created and managed a Sprint
- Added User Stories to the Sprint
- Started the Sprint
- Tracked testing activities using Jira
- Reviewed Burndown and Burnup charts
- Reviewed Epic and Release progress

---

## Zephyr Scale Activities

The following test management activities were performed using Zephyr Scale:

- Created manual test cases
- Added test steps and expected results
- Imported multiple test cases using an Excel template
- Created Test Cycles
- Added test cases to Test Cycles
- Executed test cases
- Updated test execution status
- Verified Passed and Failed test results
- Created a Regression Test Cycle
- Executed regression test cases

---

## Test Execution Workflow

1. Create test cases in Zephyr Scale.
2. Add test steps and expected results.
3. Create a Test Cycle.
4. Add the required test cases to the Test Cycle.
5. Execute each test step.
6. Update the execution status.
7. Review the overall test execution results.

---

## Reports and Metrics

The following reports and metrics were explored:

- Traceability Report
- Cycle Summary
- Execution Summary
- Burndown Chart
- Burnup Chart
- Epic Burndown
- Release Burndown

---

## Regression Testing

A Regression Test Cycle was created to verify that existing functionality continued to work after changes.

Test cases were added to the regression cycle, executed, and their execution statuses were updated based on the actual results.
